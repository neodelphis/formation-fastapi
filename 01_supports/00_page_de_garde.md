## Descriptif

Ce module introduit le développement backend professionnel avec FastAPI. Les étudiants apprennent à concevoir et structurer une API REST complète : routing, modèles de données Pydantic, authentification JWT et gestion des erreurs HTTP. La programmation asynchrone (async/await) est abordée pour la gestion des requêtes concurrentes. La partie scripting couvre l'automatisation de tâches courantes : parsing de fichiers, interaction avec des APIs tierces et création de CLI avec argparse.
